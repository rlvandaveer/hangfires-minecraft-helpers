# Helpful Minecraft Commands

## Modify Library Enchantment Trade

`/data modify entity @e[type=minecraft:villager,sort=nearest,limit=1] Offers.Recipes[7].sell.tag set value {StoredEnchantments: [{id:"minecraft:fortune", lvl:1s}]}`

/data modify entity @e[type=minecraft:villager,sort=nearest,limit=1] Offers.Recipes[9].sell.tag set value {Potion:"minecraft:weakness"}
